# Spanish 3D and game-dev terms

Use the words Spanish-speaking 3D and game-dev people actually use, not literal translations. Checked against 3DCollective (3dcollective.es, "Quad Remesher ¿Una nueva forma de modelar?"), Foro3D (foro3d.com, "Quad Remesher: adiós a la retopología manual de booleanas") and the Spanish interface of Blender.

| English | Spanish | Notes |
|---|---|---|
| retopology | retopología | Informal: "retopo". |
| automatic retopology, remeshing | retopología automática (or automatizada) | The process. |
| remesher, quad remesher | the tool's own name (QuadriFlow, Quad Remesher), described as "herramienta de retopología automática" | Never "remallador" or "remallado": they are not used. |
| Remesh modifier (Blender) | Rehacer malla | Blender's Spanish interface. |
| quad mesh, quads | malla de cuadriláteros; "quads" also appears in tutorials | Prefer "cuadriláteros" in prose. |
| mesh | malla | |
| mesh density | densidad de la malla | |
| edge flow | flujo de aristas | |
| high-poly model | modelo de alta carga poligonal | |
| polygonal modelling | modelado poligonal | |

When a term is not in this table, search Spanish sources before choosing a word, and add what you find here.
